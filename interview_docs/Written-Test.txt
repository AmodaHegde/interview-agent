         their house numbers.
         Input: An integer N and An integer array arr of size N, where arr[i] is the house
         number of the i-th friend
         Output: Return an array of size N. Each element should contain the minimum
         distance to the nearest friend for that friend

         Example
         Input
         N=3
         arr = [1, 3, 8]

         Output
         [2, 2, 5]

         Explanation:
         Friend at house 1 → nearest friend is at 3 → distance = |1 - 3| = 2
         Friend at house 3 → nearest friend is at 1 → distance = |3 - 1| = 2
         Friend at house 8 → nearest friend is at 3 → distance = |8 - 3| = 5
         So the output is:
